PAKET ALAMAT VERSI PETA (menggantikan paket alamat sebelumnya)

Perubahan: pilihan kota dihapus. Provinsi, kota, kecamatan, kode pos diisi bebas,
dan pembeli bisa menandai lokasi di peta (Leaflet + OpenStreetMap).

1. Pastikan pekerjaan sebelumnya sudah di-commit (git status = "working tree clean").

2. Ekstrak zip ke folder projek (C:\laragon\www\Website-Penjualan-Toko).
   Windows akan bertanya "Replace or Skip". Pilih REPLACE untuk semua file yang ditanyakan:
       app\Models\Address.php
       app\Http\Requests\AddressRequest.php
       app\Http\Controllers\Account\AddressController.php
       resources\views\account\addresses\_form.blade.php
       resources\views\account\addresses\index.blade.php
       resources\views\account\addresses\create.blade.php
       resources\views\account\addresses\edit.blade.php
       docs\KONTRAK_ALAMAT.md
   Semuanya file buatan paket alamat sebelumnya. Kalau teman sudah mengubah view alamat,
   JANGAN timpa view-nya; kabari saya.
   File baru: database\migrations\2026_11_22_000001_update_addresses_for_free_text_and_map.php

3. Terminal Laragon (folder projek). Pakai "migrate" BIASA, bukan migrate:fresh,
   supaya alamat yang sudah kamu buat tidak hilang (data kota lama otomatis disalin
   menjadi teks):

       php artisan migrate
       php artisan optimize:clear

   Cek di HeidiSQL: tabel "addresses" kini punya kolom province, city, district,
   postal_code, latitude, longitude, dan TIDAK punya city_id lagi.

4. Tes (login pembeli@toko.test / password, npm run dev berjalan, komputer ONLINE):
   a. Buka /akun/alamat/tambah. Peta tampil (bukan kotak abu-abu kosong).
   b. Klik satu titik di peta -> pin muncul, provinsi/kota/kecamatan/kode pos terisi.
      Geser pin -> isian ikut berubah.
   c. Ketik nama tempat di kotak "Cari" (misalnya nama kota) -> peta pindah ke sana.
   d. Ubah isian hasil otomatis secara manual -> tetap bisa disimpan.
   e. Simpan -> di daftar alamat muncul tautan "Lihat di peta".
   f. Ubah alamat tadi -> pin muncul di titik yang tersimpan, isian tidak tertimpa.
   g. Tambah alamat TANPA menyentuh peta, isi semua manual -> berhasil.
   h. Kode pos "123" -> ditolak. Nomor HP "12345" -> ditolak.
   i. Alamat lama (dibuat sebelum update) tetap tampil lengkap dengan kota dan provinsi.
   j. Tombol "Lokasi saya": hanya jalan di http://localhost atau https. Di alamat
      .test biasanya diblokir browser, itu normal.

5. Commit dan push:
       git add .
       git commit -m "Alamat: isian bebas dan pilih lokasi lewat peta"
       git push

6. Kirim docs/KONTRAK_ALAMAT.md yang baru ke teman (frontend).
