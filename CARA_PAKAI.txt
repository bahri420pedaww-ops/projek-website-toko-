PERBAIKAN: STATUS PEMBAYARAN BERUBAH SENDIRI (TANPA KLIK "CEK STATUS")

PENYEBAB
Setelah pembeli membayar (misalnya lewat DANA di halaman/tab lain), halaman pesanan yang
masih terbuka tidak tahu bahwa pembayaran sudah selesai. Dua jalur pemberitahuan otomatis
yang ada tidak menjangkaunya: webhook Midtrans tidak bisa sampai ke localhost, dan pengecekan
otomatis lainnya hanya jalan saat pembeli dikembalikan oleh popup atau pengalihan Midtrans.

PERBAIKAN
Selama pesanan berstatus "Menunggu pembayaran", halaman pesanan dan halaman bayar bertanya ke
server tiap 5 detik. Server membaca status dari database, dan kalau belum lunas, bertanya
langsung ke Midtrans (maksimal sekali per 4 detik per pesanan). Begitu status berubah, halaman
dimuat ulang dan menampilkan "Sudah dibayar" beserta pesan hijau.
  - Tidak memeriksa saat tab tersembunyi, dan langsung memeriksa saat kamu kembali ke tab itu.
  - Berhenti sendiri setelah sekitar 10 menit.
  - Kalau webhook (ngrok) aktif dan lebih dulu mengubah status, halaman ikut berubah di
    pengecekan berikutnya, tanpa menunggu Midtrans.

PASANG
1. git status harus "working tree clean" (commit dulu kalau belum).
2. Ekstrak zip ke folder projek (C:\laragon\www\Website-Penjualan-Toko).
   Pilih REPLACE untuk semua file yang ditanyakan:
       app\Http\Controllers\Shop\PaymentController.php
       app\Http\Controllers\Shop\OrderController.php
       routes\payment.php
       resources\views\shop\orders\show.blade.php
       resources\views\shop\payments\show.blade.php
   Semuanya buatan paket sebelumnya; isinya hanya DITAMBAH. OrderController sudah mencakup
   perbaikan "kembali dari Midtrans" (paket midtrans-finish), jadi aman walau paket itu belum
   dipasang. Kalau teman sudah mengubah dua view di atas, JANGAN timpa view-nya; kabari saya.
   Tidak ada migration dan tidak perlu mengedit routes/web.php.
3. Terminal Laragon:
       php artisan optimize:clear
       php artisan route:list --name=payments
   Harus muncul payments.status.

TES
a. Buat pesanan baru, klik "Bayar sekarang", bayar (DANA/VA di simulator sandbox).
   Biarkan halaman PESANAN terbuka di tab lain. Dalam sekitar 5-10 detik halaman itu berubah
   sendiri menjadi "Sudah dibayar" dengan pesan hijau, tanpa klik apa pun.
b. Pindah ke tab lain, bayar, lalu kembali ke tab pesanan: langsung diperbarui.
c. Tanpa Midtrans: php artisan payments:simulate INV-... settlement -> halaman pesanan yang
   terbuka berubah sendiri dalam 5 detik.
d. Selama belum dibayar, halaman TIDAK memuat ulang terus-menerus. Buka F12 -> tab Network:
   terlihat permintaan "status" tiap 5 detik, dan berhenti setelah status berubah.
e. Buka /pesanan/{kode pesanan orang lain}/status dengan akun lain -> 404.
f. Pesanan yang dibatalkan (misalnya lewat payments:simulate ... expire): halaman berubah
   sendiri menjadi "Dibatalkan" dengan pesan kuning.

COMMIT
       git add .
       git commit -m "Status pembayaran diperbarui otomatis di halaman pesanan"
       git push
