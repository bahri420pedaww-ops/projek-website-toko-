PAKET KATALOG DAN DETAIL PRODUK (PUBLIK)

1. Ekstrak zip ke folder projek (C:\laragon\www\Website-Penjualan-Toko).
   Semua file BARU, tidak ada yang menimpa file lama.
   Pastikan hasilnya: routes\shop.php ada di sebelah routes\web.php.

2. Buka routes/web.php, tambahkan SATU baris ini (sebelum require auth.php,
   di dekat baris require admin.php):

       require __DIR__.'/shop.php';

3. Terminal Laragon (folder projek):

       php artisan optimize:clear
       php artisan route:list --name=shop

   Harus muncul shop.products.index dan shop.products.show.
   Pastikan "npm run dev" berjalan di terminal lain supaya tampilan tidak polos.

4. Tes di browser (tanpa login juga bisa):
       /produk
       /produk?q=nama
       /produk?sort=termurah
       /produk?kategori=slug-kategori
       /produk/slug-produk
   Tes juga: nonaktifkan satu produk lewat /admin/products, lalu buka alamat
   detailnya. Harus muncul 404.

5. Commit dan push:

       git add .
       git commit -m "Tambah katalog dan detail produk (publik)"
       git push

6. Kirim docs/KONTRAK.md ke teman (frontend).
